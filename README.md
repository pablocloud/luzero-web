# Luzero - Sitio Web Oficial y Documentación (GitHub Pages)

Esta carpeta `/docs` contiene el sitio web público estático de **Luzero** listo para ser servido a través de **GitHub Pages**, cumpliendo con los requisitos obligatorios de **App Store Connect** y **Google Play Store**:

- **Página Principal (Landing / Resumen)**: `index.html`
- **Soporte y Preguntas Frecuentes (Support URL)**: `contacto.html`
- **Política de Privacidad (Privacy Policy URL)**: `privacidad.html`
- **Términos de Uso y Aviso Legal**: `terminos.html`

---

## 🚀 Cómo activar GitHub Pages en tu repositorio de GitHub

1. Entra en tu repositorio en GitHub: `https://github.com/mundosvt/app-luz` (o el nombre de tu repositorio).
2. Ve a la pestaña **Settings** (Ajustes) en el menú superior del repositorio.
3. En la barra lateral izquierda, haz clic en **Pages**.
4. En la sección **Build and deployment**:
   - **Source**: Selecciona `Deploy from a branch`.
   - **Branch**: Selecciona `main` (o tu rama principal) y en el desplegable de carpeta selecciona **`/docs`**.
5. Haz clic en **Save** (Guardar).

¡Listo! En 1-2 minutos GitHub Pages publicará tu web en:
`https://<tu-usuario-github>.github.io/app-luz/`
